# 외부 데이터 자가 수급 계획 (2026-11-06)

목표: 외부 출처가 **멈추거나 조건이 바뀌어도** 앱·가이드가 계속 돌고, 라이선스 조건(특히 위키·지도 그림의 CC BY-NC-SA)에 묶이지 않게 한다. 출처 현황은 [data-sources.md](data-sources.md).

## 원칙

1. **게임 서버·게임 파일에서 직접 뽑지 않는다.** BSG 라이선스 계약 4.3.4(외부 프로그램의 데이터 수집) 위반 소지, 게임 이미지·파일은 BSG 저작물. 우리가 읽는 건 지금처럼 이 PC 의 로그·스크린샷 파일명뿐.
2. **사실은 가져오고 문장은 우리 말로.** 탈출구 이름·좌표·조건 같은 사실은 저작권 대상이 아니지만, 위키 문장을 옮기면 NC 조건이 따라온다.
3. **새 서버 기능은 Cloudflare(Workers·R2·D1)** 에 만든다(Vercel 무료 플랜은 함수 실행 시간 한도가 빡빡).
4. 사용자 화면·좌표를 모아 데이터를 만드는 일은 **별도 동의 + BSG 위험**이 있어 하지 않는다(10-26 결정 유지).

## 3. 지도 계획 (다시 짬)

**지금 상태**: 좌표(탈출구·트랜짓·퀘스트·보스·잠긴 문 등)는 json.tarkov.dev, 그림은 tarkov.dev SVG 10맵 + 타일(연구소·미궁). 10-26 에 세웠던 "좌표로 우리가 직접 그린 지도"는 10-27 SVG 를 쓰기로 하면서 멈췄다. SVG 에는 **CC BY-NC-SA + "치트·부당 이득 도구 사용 금지"** 조건이 붙어 있어, 조건이 바뀌거나 해석 문제가 생기면 바로 빼야 하는 의존이다.

| 안 | 내용 | 크기 | 조건 |
|---|---|---|---|
| **A. 그림 없는 지도 강화** | 이미 있는 '지도 그림 끄기' 모드를 그것만으로 쓸 만하게: 탈출구·트랜짓 `outline` 다각형, 상자·잠긴 문 밀집으로 건물 위치감, 구역 이름 글자, 격자·방위 | 작음~중 | 깨끗(전부 사실 좌표) |
| **B. 우리가 그린 윤곽 지도** | 맵마다 경계·도로·주요 건물만 벡터로. 기준점 = json 좌표(문·상자·탈출구는 건물 입구·안쪽) + 개발자 본인 스크린샷 좌표. 개발용 편집 화면(`dev/map-editor.html`: 좌표 격자 위에 점·다각형, `td_maps` 변환 재사용) → `python-core/data/own_maps/<slug>.json` | 맵당 2~6시간, 많이 쓰는 맵부터(사용자 스크린샷 분포: 인터체인지·세관·삼림) | 깨끗. 게임 스크린샷 **이미지**는 쓰지 않음(BSG 저작물) |
| **C. 지도 작가 허가** | tarkov-dev-svg-maps 작가(대부분 Shebuka)에게 조건 문의 | 문의 1회 | 답에 따라 |
| D. 사용자 좌표 모으기 | — | — | 하지 않음(원칙 4) |

**순서**: 지금은 SVG 유지(앱 안 출처 표기 있음) → A 를 먼저(작고 깨끗, '그림 끄기' 사용자에게 바로 이득) → 지도 그림 조건이 걸리는 일이 생기면 C 문의 → 안 되면 B 를 많이 쓰는 맵부터.

**지도에서 남은 일(기존 dev 묶음)**: 파티 방 실게임 2인 시험·릴리즈, '바라보는 쪽 위' 회전 인게임 확인, 조회 키 공유 토글 인게임 시험, 쇄빙선 그림 정렬, 원본에 좌표 없는 보스 구역(해안선 정문 망루·광신도 숲, 터미널·쇄빙선 내부).
