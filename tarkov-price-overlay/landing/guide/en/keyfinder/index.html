Which maps are my keys for?

Drop a key tool or stash screenshot to see which map each key is for · 259 keys · data as of 2026-11-06

The image is processed only inside this browser and is never uploaded anywhere. The first run takes a few seconds to download the text recognition engine (a few MB).
Only English, Korean and Russian game text can be read — game screens in Chinese or other languages are not recognized.
Click here to choose a screenshot · drag and drop · Ctrl+V to paste Open your key tool in game, capture just the grid with Win+Shift+S, then press Ctrl+V on this page

How it works

  1. Finds the slot grid in the screenshot automatically (any resolution or margins).
  2. Reads the short name at the top of each slot and corrects misread letters against the list of key names.
  3. Groups each key under the map where it opens something. Quest keys, map entry keys and collectible keys that open nothing are marked separately.
  4. Slots that could match several keys with the same name prefix are listed under needs checking with candidates — just click the right one.

Key usage follows Keys by map(public map lock data); safes, cash registers, health resort rooms and other keys missing there are filled in from the official wiki (marked Wiki).
