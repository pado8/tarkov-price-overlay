How to redeem

  1. Launcher: account name at the top right → Activate code → enter the code → Enter. Codes are case-sensitive.
  2. Web: escapefromtarkov.com/promo/activate— logging in there and entering the code works the same.
  3. In game, log in with a character of that mode→ bottom right Messenger → collect from the sender tab. It will not arrive if your stash is full, so leave some room.
  4. Redeeming several in a row triggers a short cooldown. Redemption does not work during maintenance, so wait until the servers are back up.
  5. "Already used"appears because codes work once per account; "Invalid"appears because it expired. If you see the second one, let us know so it can be moved to the table below (Price Overlay app ⚙ → Feedback, or the DCInside Tarkov gallery).
