Официальные коды, которые работают сейчас 13 · проверено вручную 2026-11-02 · автопроверка 2026-11-04 ·

✅ активирован, чтобы сохранить в этом браузере; Синхронизация с оверлеем включена, отметка сохраняется и в приложении, и те же отметки видны в других браузерах на этом ПК. Рядом с кодом активен на n сайтах — сколько сайтов с промокодами при ежедневной автопроверке указали его как "активный", а возможно истёк означает, что ни один сайт не считает его активным, а хотя бы один — истёкшим.
Критерий включения — публикуем только коды, которые не менее 3 разных сайтов-агрегаторов за последние 2 недели отметили как "активный" и об использовании которых есть сообщения на DCInside (корейский форум). Код, который хотя бы один сайт пометил как истёкший, уходит в таблицу "Исключено" ниже. BSG не объявляет даты окончания, а некоторые коды закрывает за день, поэтому увидели — сразу вводите. Коды приходят по режимам: если активировать код PVE и зайти персонажем PVP, в мессенджере ничего не будет.

Как активировать

  1. Лаунчер: имя аккаунта справа вверху → Activate code (Активировать код) → ввести код → Enter. Регистр букв важен.
  2. Веб: escapefromtarkov.com/promo/activate: войти туда и ввести код — результат тот же.
  3. В игре зайти персонажем нужного режима→ справа внизу Мессенджер → забрать во вкладке отправителя. Если схрон переполнен, подарок не придёт — освободите место.
  4. Если вводить несколько кодов подряд, ненадолго включается кулдаун. Во время техработ активация не работает — вводите после открытия серверов.
  5. "Уже использован" — потому что код одноразовый на аккаунт, "Недействителен" — потому что истёк. Если видите второе, сообщите, чтобы мы убрали код из таблицы (приложение оверлей цен ⚙ → Обратная связь, либо DCInside (корейский форум)).
