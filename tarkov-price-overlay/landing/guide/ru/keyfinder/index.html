На каких картах мои ключи?

Загрузите скриншот ключницы или схрона — покажем, на какой карте нужен каждый ключ · ключей: 259 · данные на 2026-11-05

Изображение обрабатывается только в этом браузере и никуда не загружается. Первый запуск занимает несколько секунд: скачивается движок распознавания текста (несколько МБ).
Читается только текст игры на английском, корейском и русском — экраны игры на китайском и других языках не распознаются.
Нажмите, чтобы выбрать скриншот · перетащите · Ctrl+V чтобы вставить Откройте ключницу в игре, вырежьте сетку через Win+Shift+S и нажмите Ctrl+V на этой странице

Как это работает

  1. Автоматически находит сетку ячеек на скриншоте (любое разрешение и поля).
  2. Читает короткое название вверху каждой ячейки и исправляет ошибки распознавания по списку названий ключей.
  3. Группирует ключи по картам, где они что-то открывают. Квестовые ключи, ключи входа и коллекционные ключи без замков отмечены отдельно.
  4. Ячейки, которые подходят к нескольким ключам с одинаковым началом названия, попадают в нужно проверить с вариантами — просто выберите нужный.

Применение ключей взято из Ключи по картам(открытые данные о замках карт); сейфы, кассы, комнаты санатория и другие отсутствующие там ключи дополнены по официальной вики (метка Вики).
