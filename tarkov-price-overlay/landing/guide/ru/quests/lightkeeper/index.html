Смотритель Порядок квестов Lightkeeper

Все 15 шт. · для Каппы 0 шт. · Данные на 2026-11-03

<Неизвестно>

После 1.1.0 большинство побочных квестов открывается группами по 2~4 на каждый уровень лояльности (LL). Выполните несколько квестов из одной группы или поднимите уровень лояльности — откроется следующая группа; лишь часть квестов по-прежнему идёт цепочкой. Таблица ниже отсортирована по LL → группа → глубина цепочки → уровень — так ближе всего к "порядку, в котором квесты реально выдаются"в игре.
