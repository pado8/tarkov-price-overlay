开始使用

四个步骤

下载并安装

从 Releases 下载安装程序或便携版 ZIP。首次启动会下载一次 OCR 模型（1–5 分钟）。

把游戏语言设为英文

OCR 只能读取英文、韩文、俄文的游戏画面。在游戏设置中把语言改为 English，物品名称就会以英文显示。程序界面可以单独设为简体中文。

以管理员身份运行

塔科夫以管理员权限运行，所以覆盖层也要以管理员身份运行，否则快捷键传不到游戏里。

在游戏中按 F2

仓库里：鼠标悬停在物品上，等名称提示框出现后按 F2。战局地面上：看向物品后马上按 F2。拖动卡片的空白处可以移动它（位置会自动保存）。

FAQ

常见问题

支持中文游戏客户端吗？

不支持。本工具通过 OCR 读取游戏画面上的物品名称，目前只能识别英文、韩文和俄文的游戏客户端。请在游戏设置中把语言改为 English（推荐），程序界面可以单独设为简体中文。

程序界面有简体中文吗？

有。在设置 → 界面语言中选择“简体中文”即可，游戏语言在下一行单独设置。简体中文界面从 v1.2.7 之后的下一个版本开始提供，在此之前请先使用 English 界面。

免费吗？

完全免费，并以 MIT 协议开源。你可以在 GitHub 上查看全部代码，也可以自己编译。

会显示哪些信息？

跳蚤市场当前价格、24 小时价格范围、最近成交价、每格价格、出价最高的商人和可购买的商人、双向以物易物、藏身处制作与升级材料、需要该物品的任务及你自己的进度、同口径弹药对比表、重量效率（₽/kg）和战利品等级——全部在一张卡片上。每一行都可以在设置中单独开关。

会被封号吗？

本工具只做截屏和 OCR，不读取游戏内存，也不注入任何东西，与内存外挂、透视属于完全不同的类别。不过它没有得到 BSG 的官方认可，请自行承担使用风险——到目前为止，没有类似 OCR 覆盖层导致封号的报告。

物品识别不出来，或者显示成别的物品。

最常见的原因是捕获框没有覆盖物品名称。打开设置 → 捕获区域：捕获框会跟随鼠标，调整 X/Y 偏移，直到物品名称落在框内。QHD/4K 显示器直接按“根据显示器自动缩放”即可。另外请确认游戏语言不是中文。

在游戏里按 F2 没反应。

塔科夫以管理员权限运行，所以请右键程序 → “以管理员身份运行”，快捷键才能传到游戏里。另外请把游戏画面设为“无边框全屏”（独占全屏会在系统层面挡住所有覆盖层）。如果还是不行，请在设置中更换快捷键。

安装时出现 SmartScreen / 杀毒软件警告。

因为成本原因程序没有代码签名，并不是恶意软件。请点击“更多信息 → 仍要运行”。程序的行为和全部源代码都在 GitHub 上公开。

PVE 的价格好像不对。

请在设置中把游戏模式切换为 PVE。PVP 和 PVE 的价格数据是分开保存的。

怎么更新？

程序启动时会检查新版本，有新版本时卡片上会出现提示，点击“立即安装”即可自动下载并安装。也可以从 GitHub Releases 下载最新安装程序直接覆盖安装，或在设置中关闭自动检查。

价格数据从哪里来？

来自社区运营的公开 API tarkov.dev，不使用游戏内存或账号数据。如果该数据源出现故障，程序会自动切换到备用数据源，查价不受影响。
