개인정보처리방침

적용 대상: tarkov.aquapado.com(메인·탈콥 가이드·서비스 상태 페이지)과 Windows용 "타르코프 시세 오버레이" 앱 · 운영자: pado(aquapado.com) · 제정 2026-10-27 · 개정 2026-11-02

한 줄 요약 — 이 사이트와 앱은 이름·이메일·계정 같은 개인정보를 요구하거나 저장하지 않습니다. 사이트는 방문 집계(Vercel Web Analytics·Google Analytics)만 하고, 앱은 끌 수 있는 익명 사용 횟수만 보냅니다. 검색한 아이템 이름, 게임 화면, 좌표, 게임 메모리는 어디에도 전송되지 않습니다. 광고를 붙이게 되면 이 문서의 "광고" 항목을 먼저 갱신합니다.
웹사이트브라우저 저장소오버레이 연동오버레이 앱광고제3자 서비스보관·권리·문의

회원가입·로그인·댓글 기능이 없으므로 이름, 이메일, 비밀번호를 받지 않습니다.

2. 브라우저 저장소(이 기기에만 남는 것)

탈콥 가이드의 편의 기능은 브라우저의 로컬 저장소(localStorage·sessionStorage)에 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 삭제됩니다.

  • 퀘스트 완료·아이템 보유·건스미스 부품 체크 표시, 선택한 모드(PVP/PVE)와 필터, 지도 표시 설정
  • 오버레이 연동으로 받은 완료 퀘스트 목록과 은신처 단계(아래 3번)
  • 세션의 첫 진입 페이지(유입 비콘용, 탭을 닫으면 사라짐)

3. 오버레이 연동(선택 기능)

같은 PC에서 시세 오버레이 앱이 실행 중이면, 가이드 페이지가 이 PC 안의 앱(127.0.0.1)에서 게임 로그로 확인된 퀘스트 완료 상태와 설정한 은신처 단계를 읽어 와 "깬 퀘스트"를 자동으로 표시합니다. 이 데이터는 브라우저와 앱 사이에서만 오가며 어떤 서버에도 보내지 않습니다. 브라우저가 로컬 네트워크 접근 허용 여부를 물으면 거부해도 가이드는 정상 동작하고, 연동 표시만 빠집니다. 앱 설정의 "진행도와 함께 열기" 버튼을 쓰면 같은 데이터가 주소의 해시(#sync=) 부분에 담겨 열리며, 페이지가 읽은 뒤 주소에서 지웁니다. 해시는 서버로 전송되지 않습니다.

4. 타르코프 시세 오버레이 앱

앱이 보내는 것 — 익명 사용 통계(설정에서 끌 수 있음)

  • ✅ 앱 실행·조회(F2) 횟수, 앱 버전, 국가 코드, 무작위 설치 ID(재설치하면 바뀜), 관리자 권한 실행 여부, 조회 실패 유형(빈 화면/잡음/미일치 같은 분류만), 지도를 연 횟수
  • ✅ 조회 실패나 시세 없음일 때: 매칭된 공개 아이템 ID(검색어나 화면 글자가 아니라, 패치로 새 아이템이 생겼는지 알기 위한 공개 식별자)
  • ✅ 사용자가 직접 보낸 피드백 내용(설정 → ✉). 쓴 내용 그대로 저장되므로 개인정보를 적지 않는 것을 권합니다.
  • ❌ 보내지 않는 것: 검색한 아이템 이름, 화면 이미지, 마우스 좌표, 게임 안 좌표·맵·스크린샷, 게임 메모리, 이름·이메일 같은 개인정보, IP 주소(서버가 요청에서 국가만 뽑고 저장하지 않습니다)

통계는 기본 켜짐이며 첫 실행 때 한 번 안내하고, 설정에서 언제든 끌 수 있습니다. 끄면 그 뒤로는 아무것도 보내지 않습니다. 수집 코드는 공개 저장소의 src/App.tsx(reportEvent)에서 볼 수 있습니다.

앱이 이 PC 안에서만 읽는 것

  • 게임 화면의 아이템 툴팁 부분을 캡처해 글자를 읽습니다(OCR). 캡처 이미지는 PC 밖으로 나가지 않습니다.
  • 게임이 남기는 application 로그 파일에서 퀘스트 진행과 맵 로딩 줄을 읽어 퀘스트 트래커와 지도에 씁니다.
  • 지도: 게임이 스크린샷을 저장할 때 파일명에 적어 두는 좌표·방향만 읽습니다. 스크린샷 이미지 내용은 읽지 않고, 게임 메모리에는 접근하지 않습니다.
  • 설정(단축키·언어·은신처 단계 등)은 PC의 사용자 폴더(%LOCALAPPDATA%\TarkovPriceOverlay)와 앱 저장소에 보관됩니다.

앱이 접속하는 외부 서비스

  • 시세·퀘스트·은신처 데이터: tarkov.dev 및 json.tarkov.dev(공개 데이터). 요청에는 통상적인 접속 정보(IP 등)가 해당 서비스에 전달됩니다.
  • 업데이트 확인과 다운로드: GitHub(릴리즈 저장소)
  • 건스미스 부품 표·인앱 공지: tarkov.aquapado.com과 api.aquapado.com에서 받기만 합니다.

5. 광고

현재 이 사이트와 앱에는 제3자 광고가 없습니다. 운영비를 위해 탈콥 가이드 등 웹페이지에 Google AdSense 광고를 도입할 수 있으며, 도입하면 이 항목을 먼저 갱신합니다. 도입 시 적용되는 내용은 다음과 같습니다.

  • Google을 포함한 제3자 광고 사업자는 쿠키나 유사 기술을 사용해 이 사이트와 다른 사이트 방문 기록을 바탕으로 광고를 보여 줄 수 있습니다.
  • 개인 맞춤 광고는 Google 광고 설정에서 끌 수 있고, 다른 사업자의 쿠키는 aboutads.info에서 관리할 수 있습니다.
  • 유럽경제지역·영국·스위스 방문자에게는 광고 전에 동의 창을 띄웁니다.
  • 오버레이 앱 안에는 제3자 광고 네트워크를 넣지 않습니다. 앱 설정 화면의 "광고" 자리는 현재 운영자 자체 안내만 보여 주며, 외부 광고 코드가 실행되지 않습니다.

7. 보관 기간·이용자 권리·문의

  • 익명 사용 통계는 서비스 개선과 규모 파악 목적으로 보관하며, 개인을 식별할 수 없어 특정인의 기록으로 분리하거나 되돌릴 수 없습니다. 통계 전송을 끄면 그 시점부터 새 기록이 남지 않습니다.
  • 피드백은 처리 후 삭제를 원하면 아래 문의처로 보낸 시각과 내용 일부를 알려 주세요. 해당 기록을 삭제합니다.
  • 이 사이트와 앱은 만 14세 미만을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
  • 문의: GitHub 이슈 또는 aquapado.com의 연락처
  • 이 문서가 바뀌면 이 페이지의 날짜를 갱신하고, 수집 항목이 늘어나는 변경은 앱 공지로도 알립니다.
