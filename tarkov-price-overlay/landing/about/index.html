탈콥 가이드서비스 상태소개

사이트 소개·운영자

운영자: pado(aquapado.com) · 개인 개발자가 직접 만들고 운영하는 비공식 팬 사이트입니다.

한 줄 소개 — Escape from Tarkov를 하는 한국 플레이어가 위키를 여러 군데 뒤지지 않고 한국어로 바로 찾아볼 수 있도록 만든 사이트입니다. 퀘스트·아이템·은신처·맵 가이드와, 게임 화면에서 아이템 시세를 바로 보여 주는 무료 Windows 앱을 함께 운영합니다.

이 사이트에 있는 것

  • 탈콥 가이드 — 퀘스트 상세(목표·보상·선행 퀘스트), 상인별 진행 순서, 퀘스트·은신처에 필요한 아이템, 카파 컨테이너, 맵별 열쇠, 보스, 제작 수익, 탄약표, 프레스티지, 패치 요약, 초반 10레벨 가이드.
  • 타르코프 시세 오버레이 — 게임 안에서 아이템에 마우스를 올리고 단축키를 누르면 플리마켓·상인 시세를 띄워 주는 무료 앱. 게임 메모리를 읽거나 게임 파일을 바꾸지 않고, 화면 글자를 읽는 방식(OCR)입니다.
  • 서비스 상태 — 시세 데이터와 집계 서버가 정상인지 공개로 보여 주는 페이지.

데이터 출처와 갱신 방식

  • 퀘스트 목표, 아이템, 은신처 요구 조건, 좌표 같은 게임 수치는 커뮤니티 공개 데이터인 tarkov.dev에서 가져옵니다. 데이터가 바뀌면 가이드 페이지를 다시 생성하며, 각 페이지 아래에 데이터 기준일을 적어 둡니다.
  • 공략 설명과 팁은 공식 위키와 패치 노트를 참고해 한국어로 직접 정리했습니다. 문장을 그대로 옮기지 않습니다.
  • 아이템·퀘스트 이름은 게임 안 한국어 표기를 우선으로 씁니다.

정확도 원칙

  • 게임 패치 직후에는 데이터가 아직 반영되지 않았을 수 있습니다. 출처로 확인되지 않는 내용은 싣지 않습니다.
  • 틀린 내용을 발견하면 아래 연락처로 알려 주세요. 확인되면 고치고 기준일을 갱신합니다.
  • PVP와 PVE에서 다른 내용(퀘스트 조건, 프레스티지 등)은 모드를 나눠 적습니다.

운영비

사이트와 앱은 무료이고 회원 가입이 없습니다. 서버·도메인 비용은 운영자가 부담하고 앱에서 후원을 받고 있으며, 앞으로 가이드 페이지에 광고(Google AdSense)를 붙일 수 있습니다. 광고를 붙이더라도 본문을 가리는 팝업이나 시세 앱 안 광고는 넣지 않습니다. 광고와 개인정보에 관한 내용은 개인정보처리방침에 있습니다.
